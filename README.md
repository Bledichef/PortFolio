# Portfolio — Guillaume Colin

Site vitrine freelance : **Guillaume Colin, développeur qui automatise les workflows manuels des PME**.

🔗 **Site en ligne :** [port-folio-sepia-beta.vercel.app](https://port-folio-sepia-beta.vercel.app)

## Le positionnement

Beaucoup de PME ressaisissent encore les mêmes données à la main entre plusieurs outils. Ce site présente une offre claire : transformer ces process manuels en workflows logiciels automatisés, connectés aux outils existants (CRM, facturation, comptabilité, paiement).

## Offres présentées sur le site

**Audit Flux et Automatisation** — cartographie des process manuels et plan d'automatisation chiffré (490 € HT, 1 semaine)

**Automatisation Workflow Métier** — développement sur mesure d'une app qui remplace un process manuel (à partir de 2 490 € HT, 3 à 5 semaines)

**Apps mobile et SaaS sur mesure** — conception et développement de bout en bout (sur devis)

## Stack technique

React · TypeScript · Node.js · Python · FastAPI · .NET · React Native · Tailwind CSS

## Lancer le projet en local

npm install
npm start

Ouvre http://localhost:3000 dans le navigateur.
